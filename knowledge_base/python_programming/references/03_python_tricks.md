# Python Tricks 导读

> **面向读者**:已学完基础章节,想掌握更多 Pythonic 写法的同学

## 摘要

Dan Bader 著,2017 年发行。本书收集了 30+ 个 Python 技巧,每个 5-10 分钟可读完,适合"碎片化学习"。内容涵盖语法糖、模式识别、并发、测试等。

## 关键章节

### Part 1: 模式与习惯

- 1.1 assert 调试 vs raise 生产
- 1.2 逗号分隔的"魔法"赋值
- 1.3 上下文管理器(`with` / `@contextmanager`)
- 1.4 命名元组、dataclass
- 1.5 `__missing__` / `__getitem__` 协议

### Part 2: 美观代码

- 2.1 列表/字典/集合推导式
- 2.2 生成器表达式
- 2.3 f-string 进阶
- 2.4 海象运算符 `:=`
- 2.5 下划线命名约定

### Part 3: 通用结构

- 3.1 `*args` / `**kwargs`
- 3.2 类与对象高级用法
- 3.3 魔术方法全景
- 3.4 元类基础
- 3.5 装饰器实战

## 对 Python 课程学习的启示

- **碎片化学习**:每个 tip 独立成节,适合 5-10 分钟阅读
- **从 Pythonic 视角看基础**:同一段代码的 5 种写法对比
- **反模式警示**:每章结尾有"避坑"小贴士

## 推荐章节

- **必读**:第 4 章(类与面向对象)、第 5 章(数据结构)
- **选读**:第 2 章(模式)、第 6 章(字典)
- **进阶**:第 7-9 章(并发、测试、生态)

## 实验 1:Python 基础语法与控制流(对应 §00-§02)

**学时**:4 学时 | **难度**:★

### 实验目的

1. 熟悉 Python 开发环境(解释器 + IDE + venv)。
2. 掌握变量、数据类型、运算符、表达式。
3. 熟练运用 if-elif-else、for、while 控制流。
4. 能用列表推导式编写简洁的数据处理代码。

### 实验环境

- Python 3.12+
- IDE:VS Code + Python 扩展
- 虚拟环境:`python -m venv .venv`

### 实验步骤

#### 步骤 1:环境自检(20 分钟)

编写脚本 `env_check.py`,打印:
- Python 版本
- 当前平台
- 编码格式
- `sys.path` 包含的目录
- pip 已安装的包数量

#### 步骤 2:基础语法练习(40 分钟)

实现以下函数,每个函数独立测试:

```python
def celsius_to_fahrenheit(c: float) -> float
def fahrenheit_to_celsius(f: float) -> float
def bmi(weight_kg: float, height_m: float) -> float
def is_leap_year(year: int) -> bool
def days_in_month(year: int, month: int) -> int
```

#### 步骤 3:控制流实战(60 分钟)

实现一个"猜数字"游戏:
- 随机生成 1-100 的数字
- 用户有 7 次机会
- 每次猜错提示"太大"或"太小"
- 7 次内猜对显示"恭喜,用了 N 次"
- 7 次都没中显示"游戏结束,正确答案是 X"

要求:
- 用 `while` 循环 + `break` / `continue`
- 输入校验(非数字、范围外)
- 记录每轮猜测历史

#### 步骤 4:FizzBuzz + 高级练习(40 分钟)

- FizzBuzz 1-100
- 输出 100 以内的所有素数(用埃氏筛法)
- 列表推导式生成 Pascal 三角前 10 行
- 实现 `flatten(nested_list) -> list`(递归展平)

#### 步骤 5:数据处理实战(60 分钟)

给定文本 `text = "the quick brown fox jumps over the lazy dog the fox"`,用推导式实现:
- 统计每个单词出现次数
- 找出出现最多的 3 个单词
- 统计总字符数(去空格)
- 输出平均单词长度

### 验收标准

| 项 | 标准 |
|---|------|
| 代码可运行 | `python env_check.py` 无错 |
| 函数测试 | 5 个步骤 2 函数 + 步骤 3 游戏全部能跑 |
| 风格 | 符合 PEP 8(可用 `ruff` 检查) |
| 提交 | 实验报告 + 完整代码 |

### 拓展挑战

1. 用 `random.seed(42)` 让游戏可复现
2. 写一个简单的"菜单驱动的命令行计算器",支持加减乘除、退出
3. 探索 `dis` 模块,反汇编一段循环看 Python 字节码

## 实验 2:数据结构与文件处理(对应 §04-§05, §11-§12)

**学时**:4 学时 | **难度**:★★

### 实验目的

1. 深入掌握 list / dict / tuple / set 的特性。
2. 熟练用 CSV/JSON 读写结构化数据。
3. 用 `pathlib` 进行跨平台文件操作。
4. 综合运用数据结构解决真实业务问题。

### 实验环境

- Python 3.12+
- pytest(测试用)
- `data/` 目录存放 CSV/JSON 文件

### 实验步骤

#### 步骤 1:基础数据结构(30 分钟)

实现并测试:

```python
def merge_dicts(d1: dict, d2: dict) -> dict
def invert_dict(d: dict) -> dict
def top_k_frequent(items: list, k: int) -> list
def group_by(items: list, key) -> dict
def find_duplicates(items: list) -> list
```

每个函数用 pytest 写 3 个测试用例。

#### 步骤 2:CSV 处理(50 分钟)

给定 `students.csv`:

```csv
name,math,english,chinese,age
Alice,85,92,78,20
Bob,78,95,88,21
Carol,92,85,90,19
Dave,65,72,80,22
Eve,95,98,96,20
```

实现:
- `read_csv(path) -> list[dict]`
- `add_total_and_average(rows) -> list[dict]`
- `top_n_by_total(rows, n) -> list[dict]`
- `filter_by_age(rows, min_age, max_age) -> list[dict]`
- `write_csv(path, rows, fieldnames)`

#### 步骤 3:JSON 处理(50 分钟)

实现学生数据的 JSON 持久化:
- `save_to_json(students, path)`
- `load_from_json(path) -> list[dict]`
- `merge_classes(json1, json2) -> list[dict]`

要求:中文正常显示(`ensure_ascii=False`)、2 空格缩进。

#### 步骤 4:pathlib 实战(30 分钟)

编写一个"目录整理"脚本 `organize_files.py`:
- 接受一个目录路径
- 把目录内的文件按扩展名归类到子目录(`images/`, `docs/`, `videos/` 等)
- 用 `pathlib` 实现,支持 `--dry-run` 预览

#### 步骤 5:综合实战:学生成绩分析(60 分钟)

实现 `analyze.py`,完成:
- 读取 `students.csv`
- 计算每个学生的总分、平均分
- 计算全班平均、最高分、最低分、标准差(用 `statistics` 模块)
- 输出 JSON 报告到 `report.json`
- 找出偏科严重的学生(某科 < 平均分 20 分)

### 验收标准

- 5 个步骤的函数全部实现且通过 pytest
- `organize_files.py` 能在任意目录运行
- `analyze.py` 生成的 `report.json` 结构清晰

### 拓展挑战

1. 用 `csv.DictReader` 重做 CSV 处理
2. 用 `argparse` 给 `organize_files.py` 加 CLI
3. 用 `dataclass` 重构学生数据模型

## 实验 3:面向对象编程实践(对应 §07-§10)

**学时**:4 学时 | **难度**:★★★

### 实验目的

1. 掌握类的定义、继承、多态、封装。
2. 熟练使用 `@property` / `@classmethod` / `@staticmethod`。
3. 掌握魔术方法(运算符重载、可迭代、上下文管理器)。
4. 理解 ABC 抽象基类与鸭子类型。

### 实验环境

- Python 3.12+
- pytest

### 实验步骤

#### 步骤 1:基础类(40 分钟)

设计一个 `BankAccount` 类:
- 属性:`owner`, `balance`(封装), `_transactions`(私有)
- 方法:`deposit(amount)`, `withdraw(amount)`, `transfer(other, amount)`
- `@property balance` 受控访问
- 异常处理:余额不足、负数存款
- `__repr__` 输出 `BankAccount(owner='Alice', balance=1000)`
- `__eq__` 比较 owner 与 balance

#### 步骤 2:继承(50 分钟)

设计一个员工薪资体系:
- 基类 `Employee`(name, base_salary)
- 子类 `FullTimeEmployee` / `PartTimeEmployee` / `Intern`
- 用 `@abstractmethod` 强制 `calc_salary()`
- 实现 `Company.add_employee` / `total_payroll` / `top_earners(n)`

#### 步骤 3:运算符重载(50 分钟)

实现一个 `Vector` 类(2D / 3D):
- 支持 `+` / `-` / `*`(标量) / `@`(点积)
- 支持 `abs()`(模长)
- 支持 `==` / `hash`(放入 set)
- `__repr__` 输出 `Vector(1, 2)`

#### 步骤 4:魔术方法综合(40 分钟)

实现一个 `DeckOfCards` 类(标准 52 张扑克):
- `__len__` 返回 52
- `__getitem__` 支持索引(0='A♠', 1='2♠'...)
- `__iter__` 支持迭代
- `shuffle()` 方法(用 `random.shuffle`)
- `draw(n)` 方法返回 n 张牌

#### 步骤 5:综合实战:银行账户系统(60 分钟)

扩展实验 1,设计:
- `Account` 抽象基类
- `SavingsAccount`(年利率 2.5%) / `CheckingAccount`(支持透支 1000)
- `Bank` 聚合多个 `Account`,提供:
  - `add_account` / `find_account`
  - `total_deposits`
  - `monthly_interest`(给所有 SavingsAccount 加利息)
  - `__contains__` 支持 `account_id in bank`

### 验收标准

- 5 个步骤全部实现
- pytest 覆盖每个类至少 3 个测试
- 代码符合 PEP 8

### 拓展挑战

1. 用 `@dataclass` 重构 `Account`,比较代码量
2. 给 `Bank` 加 `__enter__` / `__exit__`,支持 `with Bank("data.json") as b:`
3. 实现 `__str__` 输出银行总览信息

## 实验 4:异常处理与标准库综合应用(对应 §13-§14)

**学时**:4 学时 | **难度**:★★★

### 实验目的

1. 掌握 try/except/else/finally 与自定义异常。
2. 熟练使用 logging、argparse、datetime、re、pathlib。
3. 写出稳健、可重试的 I/O 代码。
4. 掌握完整的 CLI 工具开发流程。

### 实验环境

- Python 3.12+
- pytest + responses(mock HTTP)

### 实验步骤

#### 步骤 1:异常处理(40 分钟)

- 实现 `safe_read_json(path)`,处理 FileNotFoundError / JSONDecodeError
- 自定义异常 `ConfigError` / `ValidationError`,继承 `AppError`
- 用 `raise from` 链接原因
- 用 `contextlib.suppress` 静默删除临时文件

#### 步骤 2:logging 配置(40 分钟)

- 配置 logging:
  - INFO 级别
  - 输出到文件 `app.log` + 控制台
  - 格式:`%(asctime)s [%(levelname)s] %(name)s: %(message)s`
- 模块化 logger:`logger = logging.getLogger(__name__)`
- 异常时用 `logger.exception()`(自动记录堆栈)

#### 步骤 3:argparse 实战(40 分钟)

构建一个 CLI 工具 `fetch.py`:
- 参数:
  - `url`(必填)
  - `-o / --output`(输出文件,默认 `output.txt`)
  - `-r / --retries`(重试次数,默认 3)
  - `-t / --timeout`(超时秒数,默认 10)
  - `-v / --verbose`
- 行为:HTTP GET url,重试,保存到文件,失败抛异常

#### 步骤 4:正则实战(40 分钟)

- 写一个 `log_analyzer.py`:
  - 解析标准日志格式:`[2026-07-12 10:30:45] INFO user.login: User alice logged in`
  - 统计各级别日志数量
  - 找出 ERROR / CRITICAL 行
  - 用 `argparse` 接受 `log_path` 参数
  - 输出 JSON 报告

#### 步骤 5:综合实战:稳健的数据迁移工具(60 分钟)

实现 `migrate.py`:
- 接受 `source` 与 `target` 两个 CSV / JSON 文件
- 读取 source,数据校验(每行字段完整性)
- 校验失败记录到 `errors.log`(含行号与原因)
- 校验通过的数据写入 target(格式可指定)
- 进度条(可选 `tqdm`,或自实现)
- 支持 `--dry-run` 预览,不实际写

### 验收标准

- `fetch.py` 接受参数并能跑(用 httpbin.org 或本地 mock)
- `log_analyzer.py` 正确解析 1000+ 行日志
- `migrate.py` 处理 10MB+ 文件不 OOM
- 所有异常有合理处理与日志

### 拓展挑战

1. 用 `concurrent.futures` 加速 `fetch.py`(并发多个 URL)
2. 加 `--resume` 断点续传(从上次失败位置继续)
3. 写单元测试覆盖每个工具

## 实验 5:综合项目——学生成绩管理系统(对应 §17)

**学时**:4 学时 | **难度**:★★★★

### 实验目的

1. 综合运用所学:数据结构、OOP、文件 I/O、异常、logging、argparse。
2. 体验完整的 CLI 工具开发流程。
3. 掌握单元测试与依赖注入。
4. 实践项目工程化组织。

### 实验环境

- Python 3.12+
- pytest
- pyproject.toml(项目配置)
- venv / uv 虚拟环境

### 实验步骤

#### 步骤 1:项目结构(20 分钟)

创建 `gradebook/` 项目:

```
gradebook/
├── pyproject.toml
├── README.md
├── src/gradebook/
│   ├── __init__.py
│   ├── __main__.py
│   ├── cli.py
│   ├── models.py
│   ├── storage.py
│   ├── service.py
│   └── logger.py
├── tests/
│   ├── test_models.py
│   ├── test_service.py
│   └── test_storage.py
└── data/
```

用 `pip install -e ".[dev]"` 安装。

#### 步骤 2:数据模型(30 分钟)

实现 `models.py`:

```python
@dataclass
class Student:
    name: str
    student_id: str
    scores: dict = field(default_factory=dict)
    # 方法:add_score, delete_score, total, average
```

#### 步骤 3:存储层(30 分钟)

实现 `storage.py`:

```python
class JSONStorage:
    def __init__(self, path: Path)
    def load(self) -> dict[str, Student]
    def save(self, students: dict[str, Student]) -> None
```

加异常处理与日志。

#### 步骤 4:服务层(40 分钟)

实现 `service.py`:

```python
class GradeBookService:
    def __init__(self, storage: JSONStorage)
    def add_student(self, name, student_id) -> Student
    def get_student(self, student_id) -> Student
    def delete_student(self, student_id) -> None
    def add_score(self, student_id, subject, score) -> None
    def list_students(self, subject=None) -> list[Student]
    def top_n(self, n) -> list[Student]
    def class_average(self) -> float
```

每个方法加参数校验、异常、log。

#### 步骤 5:CLI 层(50 分钟)

实现 `cli.py`,支持子命令:

```bash
python -m gradebook add "Alice" --id S001
python -m gradebook score --id S001 math 90
python -m gradebook list
python -m gradebook top 3
python -m gradebook delete --id S001
python -m gradebook report > report.json
```

#### 步骤 6:单元测试(40 分钟)

为 models / service / storage 写测试:

```python
def test_add_student(svc):
    s = svc.add_student("Alice", "S001")
    assert s.name == "Alice"

def test_add_invalid_score(svc):
    svc.add_student("A", "1")
    with pytest.raises(ValueError):
        svc.add_score("1", "math", 150)

# ... 共 ≥ 10 个测试
```

#### 步骤 7:功能验证(20 分钟)

启动 CLI,完整跑通所有命令,截图保存。

#### 步骤 8:文档(20 分钟)

写 `README.md`:
- 项目简介
- 安装方法
- 使用示例
- 测试方法

### 验收标准

| 项 | 标准 |

| 文档 | README 含安装/使用/测试说明 |

1. 用 SQLite 替代 JSON 存储

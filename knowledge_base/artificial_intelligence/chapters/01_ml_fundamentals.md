# 01: 机器学习基础 · 从数据中挖掘智能

> **Bloom 层级**: Understand → Apply

> **前置知识**: 00-人工智能导论、Python 基础语法

## 学习目标
1. 区分并解释机器学习的四大范式：监督学习、无监督学习、半监督学习和强化学习。
2. 掌握线性回归与逻辑回归的数学直觉，理解梯度下降优化算法的运作机制。
3. 准确描述过拟合与欠拟合的成因，并能应用正则化（L1/L2）及早停法（Early Stopping）进行缓解。
4. 熟练运用交叉验证策略评估模型性能，并根据业务场景（如医疗、反欺诈）选择正确的评估指标（精确率、召回率、F1、AUC）。
5. 了解这些经典机器学习算法在 A3 多智能体系统底层预测逻辑中的实际应用。

## 1.1 机器学习的四种范式
传统编程是“人写规则处理数据”，而**机器学习 (Machine Learning)** 是“机器从数据中自动学习规则”。
Tom Mitchell 给出了经典定义：“如果一个计算机程序在任务 T 上以 P 衡量的性能随着经验 E 而自我完善，则称这个程序从经验 E 中学习。”

根据提供给机器的**经验数据是否带有标签**，机器学习主要分为四大范式：
| 范式 | 数据标签 | 核心目标 | 典型算法与应用 |
|------|---------|---------|--------------|
| **监督学习 (Supervised)** | 有 $(x, y)$ 对 | 学习特征 $x$ 到标签 $y$ 的映射。 | 逻辑回归、决策树。用于房价预测、图像分类。 |
| **无监督学习 (Unsupervised)** | 仅有特征 $x$ | 发现数据内部的隐藏结构与相似性。 | K-means聚类、PCA。用于用户分群、异常检测。 |
| **半监督学习 (Semi-supervised)**| 少量有标签，大量无标签 | 利用海量无标签数据辅助模型提升精度。 | Pseudo-labeling。常用于标注昂贵的医学影像领域。 |
| **强化学习 (Reinforcement)** | 只有环境的奖励信号 | 智能体在环境中通过试错，最大化长期回报。 | PPO、Q-Learning。用于游戏AI、自动驾驶。 |

## 1.2 线性回归与梯度下降：机器学习的 Hello World
**线性回归 (Linear Regression)** 是最基础的监督学习预测模型，用于预测连续的数值。
**公式**：$\hat{y} = w_1x_1 + w_2x_2 + ... + b$ （寻找一条最能拟合数据散点图的直线）。
**损失函数 (Loss Function)**：我们用**均方误差 (MSE)** 来衡量模型预测值 $\hat{y}$ 和真实值 $y$ 的差距。差距越小越好。

**梯度下降 (Gradient Descent)**：
为了找到使误差最小的权重 $w$，我们不用穷举，而是让模型“下山”。计算损失函数对 $w$ 的导数（坡度），然后让 $w$ 往最陡的下坡方向走一步，步长由**学习率 ($\alpha$)** 控制。

## 1.3 逻辑回归与分类
如果我们要预测的不是具体的数值（如房价），而是离散的类别（如“是不是垃圾邮件”），就需要用分类算法。
**逻辑回归 (Logistic Regression)** 其实是做二分类的。
**直觉**：它在线性回归的外面套了一个 `Sigmoid` 函数（S型曲线），强制把线性回归吐出的任意数值，压缩到 $(0, 1)$ 区间内，从而代表**概率**。如果概率大于 0.5，我们就判为正类，否则为负类。
**损失函数**：对于概率，我们使用**交叉熵损失 (Cross Entropy Loss)**，它重重地惩罚“极其自信地给出了错误预测”的模型。

## 1.4 模型的梦魇：过拟合与欠拟合
- **欠拟合 (Underfitting)**：模型太笨，或者特征太少，连训练集上的题都做不好。**对策**：换更复杂的模型，或者增加新的特征。
- **过拟合 (Overfitting)**：模型太复杂（死记硬背），在训练集上考了 100 分，但在没见过的测试集上一塌糊涂。
  - **对策 1：正则化 (Regularization)**：在损失函数里加入对权重大小的惩罚（L1/L2 正则），逼迫模型保持简单。
  - **对策 2：早停法 (Early Stopping)**：在训练时，拿出一小批“验证集”在旁边看着，一旦发现验证集上的错误率开始上升，立刻停止训练。

## 1.5 评估指标：不仅仅是看准确率
在某些场景，**准确率 (Accuracy)** 是个骗子。比如 1000 个邮件中只有 1 个是带病毒的。模型只要永远预测“安全”，准确率就是 99.9%，但这个模型毫无价值。
我们需要看混淆矩阵衍生出的高级指标：
- **精确率 (Precision)**：模型说是阳性的，有多少是真的阳性。（宁缺毋滥）
- **召回率 (Recall)**：真正的阳性中，模型找出了多少。（宁错杀一千，不放过一个。如癌症筛查）
- **F1-Score**：精确率和召回率的调和平均，综合指标。
- **AUC-ROC**：衡量模型将正样本排在负样本前面的综合排序能力，0.5代表瞎猜，1.0代表完美。

## 1.6 教育智能体场景案例 (A3 系统)
在 A3 系统中，不仅仅有大模型进行对话，后台还默默运行着大量的经典机器学习模型：
- **学情预警系统**：使用**逻辑回归**监控学生的日常做题数据。一旦模型预测该学生期末挂科的概率超过 0.7（分类阈值），系统就会触发预警，自动调整该学生推荐路径的难度，并让 `Tutor Agent` 增加基础知识点的讲解频率。
- **数据处理引擎**：学生提交的作答文本会通过**词袋模型 (TF-IDF)** 等传统特征工程转化为数值向量，再输入到分类器中，以保证极低的延迟。

## 1.7 常见误区
- **误区 1：在评估模型泛化能力时，直接把所有的历史数据拿去训练，然后在同样的数据上进行测试。**
  - **为什么错**：这叫“数据泄露”。这样测出来的 100% 准确率完全是自欺欺人。必须在训练前严格切分出**训练集和测试集**，或者使用**交叉验证（Cross-Validation）**来保证测试数据的纯洁性。
- **误区 2：在梯度下降时，学习率（Learning Rate）设置得越大越好，这样模型能更快学完。**
  - **为什么错**：如果学习率过大，模型在下山时会“步子迈得太大”，直接跨过谷底，在山谷两边剧烈震荡甚至发散（损失飙升为无穷大）。学习率通常需要从 `0.01` 或 `0.001` 开始谨慎调试。
- **误区 3：如果模型出现了过拟合，直接砍掉一半的训练数据来让模型不要记那么多。**
  - **为什么错**：减少训练数据是**最糟糕**的抗过拟合方法，这反而会让模型更容易记住剩下的那些少数数据。正确的做法是**增加**训练数据，或者增强数据，同时使用正则化。

## 1.8 可运行示例：纯 NumPy 实现线性回归与梯度下降
为了让你彻底弄懂梯度下降的底层逻辑，下面这个脚本没有使用任何高级机器学习库（如 sklearn），纯手工计算梯度并拟合数据。

```python
import numpy as np

def gradient_descent(X, y, learning_rate=0.01, epochs=1000):
    """
    使用梯度下降求解线性回归的纯手工实现
    """
    # 样本数量 n，特征维度 d
    n, d = X.shape
    # 随机初始化权重 w 为全 0
    w = np.zeros(d)
    
    print("开始训练...")
    for epoch in range(epochs):
        # 1. 前向预测: y_pred = X * w
        y_pred = np.dot(X, w)
        
        # 2. 计算误差: 预测值 - 真实值
        error = y_pred - y
        
        # 3. 计算梯度: (2/n) * X.T * error
        gradient = (2 / n) * np.dot(X.T, error)
        
        # 4. 梯度下降: 向负梯度方向走一步
        w = w - learning_rate * gradient
        
        # 5. 每 200 轮打印一次 MSE 损失
        if epoch % 200 == 0:
            mse_loss = np.mean(error ** 2)
            print(f"Epoch {epoch:4d} | MSE 损失: {mse_loss:.4f} | 当前权重: {w}")
            
    return w

if __name__ == "__main__":
    np.random.seed(42)
    # 模拟数据：假设我们要拟合的目标真实方程是 y = 3*x_1 + 2*x_2 + 1
    # 我们故意加入一点正态分布的噪声，模拟真实世界的脏数据
    X_features = np.random.rand(100, 2) * 10
    # 为了拟合常数项 1，我们在特征矩阵的最左边加一列全为 1 的“偏置列”
    X_b = np.c_[np.ones((100, 1)), X_features]
    
    y_true = 1 + 3 * X_features[:, 0] + 2 * X_features[:, 1] + np.random.randn(100) * 0.5
    
    print("真实权重应该是接近: [1.0, 3.0, 2.0]")
    
    # 执行梯度下降，尝试找回这几个权重
    final_w = gradient_descent(X_b, y_true, learning_rate=0.01, epochs=1000)
    
    print(f"\n训练结束！模型学习到的最终权重: {np.round(final_w, 2)}")
```

## 1.9 本章小结
1. 机器学习的本质是让计算机利用算法解析数据，从中学习规律并进行预测或决策。
2. 线性回归与逻辑回归是监督学习的基石，前者预测连续数值，后者处理离散分类。
3. 梯度下降是一切机器学习（包括深度学习）模型优化的核心引擎。
4. 在模型评估中，除了追求完美的拟合（防范过/欠拟合），更要根据业务实际代价选择合适的指标（如医疗重召回，风控重精确）。
5. 经典的 ML 模型在 A3 教育系统中承担着大量轻量化、高频次的后台决策任务。

## 1.10 练习思考
1. **指标应用**：如果在 A3 系统中我们要开发一个“学生作弊检测”模块，为了尽量不冤枉任何一个好学生，我们应该把哪一个评估指标（精确率、召回率、准确率）放在绝对优先级？为什么？
2. **正则化探索**：L1 正则化（Lasso）和 L2 正则化（Ridge）在惩罚模型权重时有一个非常显著的区别：L1 会导致很多权重直接变成 0，而 L2 只是让权重变小但不为 0。查阅资料，解释为什么 L1 能实现“特征选择”的效果？
3. **梯度下降陷阱**：在上述的代码示例中，如果我们把 `learning_rate` 从 `0.01` 改成 `100.0`，你猜程序输出的 Loss 会变成什么？请亲自运行代码尝试一下。
4. **模型对比**：监督学习需要大量的标注数据，但在教育场景下，让老师给几万份作业打标签非常耗时。你能想到如何利用“半监督学习”的思路来缓解这个数据荒吗？

# 人工智能导论 —— 课程知识库

本知识库作为「A3 个性化学习智能体系统」的初始课程数据，涵盖人工智能核心知识体系。

## 第1章 人工智能概述

### 1.1 人工智能的定义
人工智能（Artificial Intelligence, AI）是计算机科学的一个分支，致力于研究和开发能够模拟、延伸和扩展人类智能的理论、方法、技术和应用系统。

**核心能力**：
- 感知能力：图像识别、语音识别、自然语言理解
- 推理能力：逻辑推理、因果推理、常识推理
- 学习能力：从数据和经验中学习
- 决策能力：在不确定环境下做出最优决策

### 1.2 人工智能发展简史

| 阶段 | 时间 | 关键事件 |
|------|------|---------|
| 诞生期 | 1956 | 达特茅斯会议，"人工智能"概念正式提出 |
| 第一次繁荣 | 1956-1974 | 通用问题求解器 GPS、ELIZA 聊天程序 |
| 第一次寒冬 | 1974-1980 | 计算能力不足，期望过高 |
| 专家系统时代 | 1980-1987 | MYCIN 医疗专家系统、R1 配置系统 |
| 第二次寒冬 | 1987-1993 | 专家系统维护困难 |
| 统计学习兴起 | 1993-2011 | SVM、随机森林、深蓝击败卡斯帕罗夫 |
| 深度学习革命 | 2012-2022 | AlexNet、AlphaGo、GPT 系列、扩散模型 |
| 大模型时代 | 2022-至今 | ChatGPT、GPT-4、多模态大模型 |

### 1.3 人工智能的分类
- **弱人工智能 (Narrow AI)**：专注于特定任务，如图像分类、语音识别
- **通用人工智能 (AGI)**：具备人类水平的通用智能（目前尚未实现）
- **超级人工智能 (ASI)**：超越人类智能的系统（理论概念）

## 第2章 机器学习基础

### 2.1 机器学习概念
机器学习是一种通过数据和经验自动改进算法性能的方法，无需显式编程。

**核心范式**：
- **监督学习**：从标注数据学习输入到输出的映射。典型任务：分类、回归
- **无监督学习**：从无标注数据中发现结构和模式。典型任务：聚类、降维
- **强化学习**：通过与环境交互获得奖励信号来学习策略

### 2.2 监督学习算法

#### 2.2.1 线性回归
线性回归是最基础的回归算法，假设输出与输入之间存在线性关系。

**模型公式**：y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

**损失函数**：均方误差 MSE = (1/n) Σ(yᵢ - ŷᵢ)²

**优化方法**：梯度下降法

#### 2.2.2 逻辑回归
用于二分类问题，通过 Sigmoid 函数将线性输出映射到 [0, 1] 概率区间。

**Sigmoid 函数**：σ(z) = 1 / (1 + e⁻ᶻ)

#### 2.2.3 决策树
基于特征条件进行逐层划分的树形模型。

**关键概念**：
- 信息增益（ID3）
- 信息增益率（C4.5）
- 基尼系数（CART）

#### 2.2.4 支持向量机 (SVM)
在特征空间中寻找最大间隔超平面的分类算法。

**核函数**：线性核、多项式核、高斯核(RBF)

### 2.3 无监督学习

#### 2.3.1 K-Means 聚类
将数据划分为 K 个簇，使得簇内数据点相似度最高。

**算法步骤**：
1. 随机初始化 K 个聚类中心
2. 将每个数据点分配到最近的聚类中心
3. 重新计算聚类中心
4. 重复步骤 2-3 直到收敛

#### 2.3.2 主成分分析 (PCA)
通过正交变换将数据投影到方差最大的方向上，实现降维。

### 2.4 模型评估

**分类指标**：
- 准确率 (Accuracy) = 正确预测数 / 总预测数
- 精确率 (Precision) = TP / (TP + FP)
- 召回率 (Recall) = TP / (TP + FN)
- F1 Score = 2 × Precision × Recall / (Precision + Recall)

**回归指标**：
- MAE (平均绝对误差)
- MSE (均方误差)
- R² (决定系数)

**防止过拟合**：交叉验证、正则化 (L1/L2)、早停、Dropout

## 第3章 深度学习

### 3.1 神经网络基础

#### 3.1.1 感知器
最简单的神经网络模型，包含输入层和输出层。

**结构**：输入 → 加权求和 → 激活函数 → 输出

#### 3.1.2 多层感知器 (MLP)
在输入层和输出层之间加入隐藏层，增强模型表达能力。

**激活函数**：
- Sigmoid: σ(x) = 1/(1+e⁻ˣ)
- ReLU: f(x) = max(0, x)
- Tanh: f(x) = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ)

#### 3.1.3 反向传播算法
通过链式法则从输出层反向逐层计算梯度，更新网络参数。

**核心思想**：
1. 前向传播：计算预测值
2. 计算损失
3. 反向传播：计算各层参数的梯度
4. 参数更新：w = w - η × ∂L/∂w

### 3.2 卷积神经网络 (CNN)

**核心组件**：
- **卷积层**：通过卷积核提取局部特征
- **池化层**：降低空间维度（最大池化、平均池化）
- **全连接层**：特征汇总与分类

**经典架构**：
| 模型 | 年份 | 特点 |
|------|------|------|
| LeNet-5 | 1998 | 手写数字识别的开创之作 |
| AlexNet | 2012 | 深度学习革命的标志 |
| VGGNet | 2014 | 使用小卷积核堆叠 |
| GoogLeNet | 2014 | Inception 模块 |
| ResNet | 2015 | 残差连接，解决深层训练问题 |

### 3.3 循环神经网络 (RNN)

用于处理序列数据（文本、时间序列）。

**变体**：
- **LSTM**：长短期记忆网络，通过门控机制解决长期依赖问题
  - 遗忘门、输入门、输出门
- **GRU**：门控循环单元，LSTM 的简化版本
  - 更新门、重置门

### 3.4 Transformer 架构

**核心机制：自注意力 (Self-Attention)**

Attention(Q, K, V) = softmax(QKᵀ / √dₖ) × V

**优势**：
- 并行计算能力强
- 长距离依赖建模
- 可扩展性好

**组成部分**：
1. 多头注意力 (Multi-Head Attention)
2. 前馈神经网络 (FFN)
3. 残差连接 + 层归一化
4. 位置编码 (Positional Encoding)

## 第4章 自然语言处理 (NLP)

### 4.1 文本预处理
- 分词（中文：jieba；英文：空格分割）
- 去除停用词
- 词干提取 / 词形还原
- 文本向量化：词袋模型、TF-IDF

### 4.2 词向量
- **Word2Vec**：CBOW、Skip-gram
- **GloVe**：基于全局共现矩阵
- **FastText**：考虑子词信息

### 4.3 预训练语言模型
| 模型 | 类型 | 特点 |
|------|------|------|
| BERT | 编码器 | 双向上下文理解，适合分类/NER |
| GPT | 解码器 | 自回归生成，适合文本生成 |
| T5 | 编码器-解码器 | 将所有NLP任务统一为文本到文本 |

### 4.4 大语言模型 (LLM)
- **Scaling Law**：模型性能随参数量、数据量、计算量增长
- **涌现能力**：推理、代码生成、多步任务规划
- **对齐技术**：RLHF（基于人类反馈的强化学习）
- **提示工程**：Zero-shot、Few-shot、Chain-of-Thought (CoT)

## 第6章 强化学习

### 6.1 基本概念
- **智能体 (Agent)**：做出决策的主体
- **环境 (Environment)**：智能体交互的对象
- **状态 (State)**：环境的描述
- **动作 (Action)**：智能体的行为
- **奖励 (Reward)**：环境反馈的信号
- **策略 (Policy)**：状态到动作的映射

### 6.2 核心算法
- **Q-Learning**：基于值函数的无模型算法
- **DQN**：深度 Q 网络，用神经网络近似 Q 值函数
- **Policy Gradient**：直接优化策略函数
- **PPO**：近端策略优化，目前最常用的策略梯度算法
- **Actor-Critic**：结合值函数和策略函数的优势

### 6.3 应用场景
- 游戏 AI（AlphaGo、OpenAI Five）
- 机器人控制
- 推荐系统
- 大语言模型对齐（RLHF）

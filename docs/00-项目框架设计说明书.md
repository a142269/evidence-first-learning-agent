## 二、学术前沿参考

### 2.1 核心论文参考

**GenMentor** (WWW 2025 Oral, Microsoft Research + HKUST):  
- 提出 Skill Gap Identifier → Adaptive Learner Modeler → Path Scheduler → Content Generator → Chatbot Tutor 五 Agent 架构
- 关键借鉴：**目标→技能映射**（Goal-to-Skill Mapping）、**探索-起草-整合**（EDI）内容生成机制
- 我们创新：在其基础上增加 **Realtime State Analyzer**，将"学生当前状态"纳入路径规划决策

**EduPlanner** (IEEE TLT 2025, 浙江大学 + 华中师大):  
- 提出 Skill-Tree + CIDDP 五维评估 + 三 Agent 对抗协作
- 关键借鉴：**Skill-Tree 能力树**（数值/抽象/逻辑/类比/空间）、**CIDDP 多维评估**（清晰/完整/深度/实用/针对）
- 我们创新：将 Skill-Tree 改造为 **动态知识图谱**，节点包含掌握度/置信度/最后复习时间/关联节点

**PETRA** (IEEE 2025):  
- 六 Agent 协同：Code Generator + Scorer + Compiler + Reasoner + Visualizer + Orchestrator
- 关键借鉴：**可视化辅助理解**（Visualizer Agent 对应我们的 Mermaid 图解生成）

**对话画像构建** (EMNLP 2024, UMAP 2024):  
- 关键借鉴：**Gazetteer-based NER + LLM Prompt** 双通道特征抽取；**认知+人格** 双维度学生建模
- 我们创新：纯规则引擎实时学情（<100ms），不依赖 LLM 分析延迟

### 2.2 开源项目参考

**NPUYUN/LearnPath**（同赛题成熟方案）:  
- 借鉴：双层画像、实时学情、LLM 降级路由、Reviewer 质检、AI 课堂概念
- 差异化：我们使用自研 Orchestrator + Agent Protocol（非 LangGraph）、8维画像（vs 7维）、规则引擎实时学情（非 LLM）

### 2.3 产业最佳实践

## 四、核心创新设计：双环学习引擎

> 这是本项目的**最大创新点**，也是答辩时的核心卖点。

### 4.1 设计理念

传统学习系统是"单环"的：用户请求 → 系统生成 → 输出结果。我们设计了**双环学习引擎**，将"感知"和"执行"解耦为两个独立但协同的循环。

```
              ┌──────────────────────────────────────┐
              │         感知环 (Perception Loop)       │
              │        每次对话触发，<100ms完成          │
              │                                      │
              │  用户消息                               │
              │    ↓                                  │
              │  规则引擎分析（关键词+模式+上下文）        │
              │    ↓                                  │
              │  更新实时学情（6维）：                    │
              │  情绪 │ 困惑度 │ 投入度 │ 负荷 │ 疲劳 │ 信心│
              │    ↓                                  │
              │  驱动个性化策略 Prompt                    │
              └──────────────┬───────────────────────┘
                             │ 策略约束
              ┌──────────────▼───────────────────────┐
              │         执行环 (Execution Loop)        │
              │        按需触发，Agent协同完成            │
              │                                      │
              │  意图识别 → 任务DAG → 并行执行            │
              │    ↓                                  │
              │  Agent 接收感知环的策略约束               │
              │  如"困惑度高→降压讲解模式"                │
              │    ↓                                  │
              │  生成个性化响应 → Reviewer质检            │
              │    ↓                                  │
              │  SSE流式输出 + 更新长期画像               │
              └──────────────────────────────────────┘
```

### 4.2 感知环：实时学情6维

| 维度 | 含义 | 检测方式 | 驱动行为 |
|------|------|---------|---------|
| **困惑度** | 0-1，越高越困惑 | 正则匹配"不懂/太难/什么意思" + 上下文 | >0.6 切换降压讲解模式 |
| **情绪状态** | neutral/excited/frustrated/tired | 关键词+"算了/放弃"=挫败，"原来如此/懂了"=兴奋 | 挫败→共情回复，兴奋→引入进阶 |
| **投入度** | low/medium/high | "继续/然后呢/我来试试"=高，"嗯/哦"=低 | 低投入→主动提问激活 |
| **认知负荷** | 0-1 | "公式/推导/抽象/记不住"频率 | >0.6 建议拆分知识点 |
| **疲劳度** | 0-1 | "累了/困了/太多/学不完" | >0.5 主动建议休息 |
| **学习信心** | 0-1 | 历史正确率 + 交互态度 | <0.3 增加鼓励和简单题 |

### 4.3 执行环：8 Agent × 6 资源

**Agent 清单**：

| Agent | 注册名 | 核心能力 | 输出类型 |
|-------|--------|---------|---------|
| ProfileAgent | profile | 对话提取8维画像特征 | profile_updates JSON |
| CourseExpertAgent | course_expert | 基于RAG生成讲解文档+拓展阅读 | Markdown文档 |
| QuizGeneratorAgent | quiz_generator | 生成选择/填空/判断/简答/编程5类题 | Markdown + quiz_json |
| PathPlannerAgent | path_planner | 基于画像+知识图谱规划学习路径 | learning_path JSON |
| MultimodalAgent | multimodal | 生成Mermaid思维导图+代码案例+PPT大纲 | Markdown + mermaid |
| TutorAgent | tutor | 多模态答疑（文字+图解+代码） | Markdown（混合格式） |
| EvaluatorAgent | evaluator | 6维学习效果评估+路径调整建议 | evaluation_result JSON |
| ReviewerAgent | reviewer | 资源质量审查（快速规则+LLM深度） | review_result JSON |

**资源类型（6种）**：

| # | 类型 | 生成Agent | 输出格式 |
|---|------|----------|---------|
| 1 | 课程讲解文档 | CourseExpertAgent | Markdown（含标题/列表/代码块/公式） |
| 2 | 思维导图 | MultimodalAgent | Mermaid mindmap |
| 3 | 练习题 | QuizGeneratorAgent | Markdown + quiz_json（5类题型） |
| 4 | 拓展阅读 | CourseExpertAgent | Markdown（含引用来源） |
| 5 | 代码实操案例 | MultimodalAgent | 对应语言代码块 + 注释 + 运行说明 |
| 6 | 课件提纲 | MultimodalAgent | 结构化Markdown（## 分隔页） |

**数据模型**（8维长期画像）：

```python
StudentProfile = {
    "student_id": "唯一标识",
    "dimensions": {
        "knowledge_base":    {"score": 0.0-1.0, "level": "初级/中级/高级", "evidence": [...]},
        "cognitive_style":   {"score": 0.0-1.0, "level": "视觉型/听觉型/动手型/读写型"},
        "learning_preference":{"score": 0.0-1.0, "level": "视频/文档/练习/项目"},

        "time_management":   {"score": 0.0-1.0, "level": "充裕/中等/紧张"},
        "self_efficacy":     {"score": 0.0-1.0, "level": "高/中/低"},
        "interaction_pattern":{"score": 0.0-1.0, "level": "主动型/被动型/合作型"},
    },
    "knowledge_graph": {           # 知识点→掌握度

        "梯度下降": 0.4,
        "卷积神经网络": 0.2,
    },

### 5.2 多智能体资源生成（功能2）

**编排流程**：

```
用户输入："帮我讲解CNN的原理，再出几道题"

    ↓ [Orchestrator 意图识别]
    意图: ["generate_doc", "generate_exercise", "profile_update"]

    ↓ [任务DAG生成]
    task_0: profile_update (priority=1)
    task_1: generate_doc (priority=2, depends_on=[task_0])
    task_2: generate_exercise (priority=2, depends_on=[task_0])

    ↓ [并行执行 priority=2 的任务]
    CourseExpertAgent.generate()  ←→  QuizGeneratorAgent.generate()

    ↓ [Reviewer 质检]
    ReviewerAgent.review(doc_result)
    ReviewerAgent.review(quiz_result)

    ↓ [结果聚合 + SSE流式输出]
    {
      "doc": "## 卷积神经网络(CNN)详解\n...",
      "quiz": "## CNN 练习题\n### 选择题\n1. ..."
    }
```

### 5.3 学习路径规划（功能3）

| L1 | 意图层 | 学生想学什么？ | 对话目标、画像学习目标 |
| L2 | 锚点层 | 有什么线索？ | 收藏资源、资料库选择 |
| L3 | 行为层 | 学得怎么样？ | 练习成绩、完成率、浏览记录 |
| 分析层 | 综合报告 | 整体画像+实时状态 | 长期画像 + 实时学情 + 行为信号 |

### 5.4 智能辅导（功能4，加分）

**多模态回复策略**（基于实时学情驱动）：

| 实时学情信号 | 回复策略 |
|-------------|---------|
| 困惑度 > 0.6 | 降压模式：一句话直觉 → 生活化类比 → 最多3步拆解 |
| "不太懂" + 连续追问 | 切换解释角度，用图解(Mermaid)辅助 |
| 涉及代码 | 完整示例代码 + 逐行注释 + 运行结果 |
| 数学概念 | 公式 + 推导 + 直觉解释 |
| 认知负荷 > 0.6 | 精简内容，只聚焦核心要点，建议休息 |

### 5.5 学习效果评估（功能5，加分）

**六维评估模型**（借鉴 EduPlanner CIDDP + 自研）：

| 维度 | 评估内容 | 数据来源 |
|------|---------|---------|
| 知识掌握度 | 练习题正确率 | QuizGenerator 结果 |
| 应用能力 | 编程题/应用题完成度 | 实操案例提交 |

## 八、知识库工程

### 8.1 知识库构建流水线（借鉴旧项目ETL经验）

```
课程文档(Markdown)
  ↓ 解析（识别标题/段落/代码块/表格）
  ↓ 清洗（去页码/去页眉页脚/去空白行）
  ↓ 标准化（知识点别名统一：ML→机器学习, CNN→卷积神经网络）
  ↓ 分块（每块2000字符，200字符重叠）
  ↓ Embedding（bge-base-zh-v1.5，768维）
  ↓ 存入ChromaDB（含metadata：知识点/难度/类型/来源）
```

### 8.2 知识点标准化映射（示例）

| 别名 | 标准名称 |
|------|---------|
| ML, Machine Learning, 统计学习 | 机器学习 |
| DL, Deep Learning, 深度网络 | 深度学习 |
| CNN, ConvNet, 卷积网络 | 卷积神经网络 |
| RNN, 循环网络, 递归网络 | 循环神经网络 |
| NLP, 自然语言, 文本处理 | 自然语言处理 |
| SGD, Stochastic Gradient Descent | 随机梯度下降 |

### 8.3 RAG 检索增强生成流程

```
用户问题："CNN的卷积操作是怎么做的？"
  ↓ 1. 向量检索 (ChromaDB query, top_k=5)
  ↓ 2. 相关性排序（cosine similarity）
  ↓ 3. 拼接上下文（5个chunks → 拼接为RAG context）
  ↓ 4. 注入 Agent Prompt
CourseExpertAgent.system_prompt + 
  "【课程知识库参考】\n[参考1] CNN的卷积层通过...\n[参考2] 常见的卷积核大小...\n"
  + user_prompt
  ↓ 5. LLM生成
  ↓ 6. Reviewer 质检（来源引用检查）
```

## 十、防幻觉与安全体系

### 10.1 四级防线

| 级别 | 防御层 | 机制 | 响应时间 |
|------|--------|------|---------|
| L1 | RAG引用 | 所有事实性陈述可追溯到知识库chunk | 检索阶段 |
| L2 | 内容安全过滤 | 敏感词匹配 + 正则模式检测 | <5ms |
| L3 | 一致性检查 | 生成内容与RAG context相似度对比 | <50ms |
| L4 | Reviewer质检 | 快速规则(提示词复述/JSON残留/过短) + LLM深度审查 | 快检<5ms + 深度<3s |

### 10.2 快速质检规则（毫秒级，不调用LLM）

```python
def quick_quality_check(content):
    issues = []
    
    # 检查1: 提示词复述
    if re.search(r"你是一名.{0,30}请根据以下要求", content):
        issues.append("内容中包含了AI生成指令的复述")
    
    # 检查2: JSON格式残留
    if re.search(r'```json\s*\n\s*\{', content) and len(content) < 200:
        issues.append("疑似返回了JSON格式数据而非教学内容")
    
    # 检查3: 内容过短
    if len(content.strip()) < 100:
        issues.append(f"生成内容过短({len(content)}字符)")
    
    return issues
```

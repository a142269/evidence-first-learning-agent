# 教师端 2 分钟录制剧本：知识库建设与防幻觉边界

## 录制目标

在约 2 分钟内证明教师端形成了一个可核验的闭环：

> 教师上传课程资料 → KnowledgeGuard 审核 → 自动索引 → 命中测试验证来源 → 生成课程知识图谱 → 学情诊断 → 教学提示/视频生成 → CoV-Edu 安全核验。

## 防幻觉边界的录制口径

请严格按以下方式讲，避免做超出当前页面能力的承诺：

- 可以说：**“该问题没有匹配的课程证据，低分候选不能作为可信引用。”**
- 不要说：**“页面一定不会返回任何结果。”** 当前命中测试会返回 Top 5 候选；当问题完全无关时，可能仍会显示低相关度片段。
- 最有说服力的镜头是：问题为“北宋汝窑天青釉开片纹的鉴定方法有哪些？”，但返回来源是人工智能课程文档，且相似度很低。此时明确指出“来源不匹配，因此不能据此回答”。
- 如果页面出现“未召回任何片段”，可补充一句：**“严格模式下，知识库未覆盖时应明确提示证据不足，而不是编造内容。”**

## 图谱不显示整篇文章时的说明

知识图谱展示的是文章中提取出的知识点和关系，不会展示整篇原文。为了让“反向传播与优化器”在图谱中更明显，请确保上传文档保留如下 Markdown 标题结构：

```md
# 反向传播与优化器
## 学习目标
## 为什么需要反向传播？
## 计算图与链式法则
```

要证明全文已入库，请使用“命中测试”查看原文片段和来源；要展示结构化结果，请使用“生成知识点图谱”。

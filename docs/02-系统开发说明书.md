## 3. 核心模块设计

### 3.1 多智能体编排（Agent Orchestrator）

**设计思想**：借鉴旧项目 services/ 分层调用 + rules/ 规则引擎的协同模式。

**工作流程**：
```
用户输入 → 意图识别（规则+LLM）
        → 任务DAG生成（优先级+依赖）
        → 并行执行（同优先级）
        → 结果聚合
        → 流式输出
```

**Agent 通信协议**：
- `AgentContext`：统一输入（user_input, profile, history, rag_results）
- `AgentResponse`：统一输出（content, content_type, resources, profile_updates）
- 每个 Agent 继承 `BaseAgent`，实现 `execute()` 方法

### 3.2 实时学情感知（Realtime State）

**设计来源**：借鉴 NPUYUN/LearnPath 的双层画像设计理念。

**两层画像**：
| 层次 | 名称 | 回答的问题 | 更新频率 |
|------|------|-----------|---------|
| 长期 | Learning Profile | 你是谁、基础怎样 | 每轮对话增量更新 |
| 短期 | Realtime State | 你现在怎样 | 每条消息实时分析 |

**分析维度**：
- 情绪（emotion）：confused / frustrated / excited / neutral
- 困惑度（confusion_level）：0-1，基于关键词匹配 + 上下文
- 投入度（engagement）：low / medium / high
- 认知负荷（cognitive_load）：0-1
- 疲劳度（fatigue_level）：0-1
- 卡点主题（stuck_topics）：自动提取

**状态平滑机制**：
- 单条消息权重0.7 + 历史状态权重0.3
- 无新信号时缓慢衰减（如困惑度 ×0.7/轮）
- 避免单条消息导致的剧烈跳变

### 3.3 LLM 多通道降级路由

**路由链**：Kimi(优先) → 星火 → 辅助模型 → Mock兜底

**降级触发条件**：
- 超时（30秒）
- API 返回错误
- 返回内容无效（空/错误前缀）
- 环境变量未配置（自动跳过）

**Mock 模式**：无任何 API Key 时，系统返回友好的 Demo 提示，前端全功能可操作。

### 3.4 资源质量审查（Reviewer Agent）

**快速规则检查**（毫秒级，不调用 LLM）：
- 提示词复述检测
- JSON 格式残留检测
- 内容长度不足检测

**LLM 深度审查**（秒级）：
- 主题相关性
- 结构完整性
- 学术准确性
- 可读性
- 原创性

## 5. 数据库设计

### 5.1 核心表（SQLite）

```sql
-- 用户表
CREATE TABLE users (
    id TEXT PRIMARY KEY,
    nickname TEXT,
    student_id TEXT UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 学习画像表
CREATE TABLE learning_profiles (
    user_id TEXT PRIMARY KEY,
    profile_data JSON,          -- 8维画像数据
    profile_version INTEGER DEFAULT 1,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 实时学情表
CREATE TABLE realtime_states (
    user_id TEXT PRIMARY KEY,
    state_data JSON,            -- 困惑度/投入度/情绪等
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 学习资源表
CREATE TABLE resources (
    id TEXT PRIMARY KEY,
    user_id TEXT,
    type TEXT,                  -- document/mindmap/quiz/code/reading
    title TEXT,
    content TEXT,
    content_type TEXT DEFAULT 'markdown',
    agent_name TEXT,
    metadata JSON,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 学习路径表
CREATE TABLE learning_paths (
    id TEXT PRIMARY KEY,
    user_id TEXT,
    title TEXT,
    stages JSON,                -- 路径阶段列表
    current_stage INTEGER DEFAULT 0,
    progress REAL DEFAULT 0.0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 6. 部署说明

### 6.1 环境配置

```bash
# 1. 克隆项目
cd A3-learning-agent-system

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API 密钥

# 3. 安装依赖
pip install -r requirements.txt
cd frontend && npm install && cd ..

# 4. 启动后端
uvicorn backend.app.main:app --reload --port 8000

# 5. 启动前端（新终端）
cd frontend && npm run dev
```

### 6.2 Docker 部署

```bash
docker-compose up -d
# 后端: http://localhost:8000
# 前端: http://localhost:5173
```

## 8. 创新点总结

1. **双层画像体系**：长期画像 + 实时学情，从"你是谁"到"你现在怎样"
2. **12 Agent + 1 Orchestrator 协同**：Profile / CourseExpert / QuizGenerator / PathPlanner / Multimodal / Tutor / Evaluator / Reviewer / Critic / DebateModerator / COVVerifier / TextbookQA + AgentOrchestrator 编排器
3. **实时学情驱动教学策略**：困惑度高自动降压、疲劳主动建议休息、好奇引入拓展
4. **LLM 多通道降级路由 + PromptCache**：Kimi → 星火 → 辅助 → Mock + SHA-1 命中走本地，确保系统可用性
5. **四级防幻觉机制**：RAG 来源引用 + 一致性检查 + Reviewer 质检 + CoV 声明级验证；外加 P1.2 ClaimLedger 5 source type 证据链
6. **状态平滑融合算法**：避免单条消息引发画像剧烈跳变
7. **P1.1 Pedagogical Safety / Scaffolding Guard**（教育场景专有）：4 字段评估 + critic 维度适配，10ms 纯规则
8. **GraphRAG 2-hop + HyDE + RRF 三路融合**：知识图谱邻居扩展 + 假设答案检索 + RRF 公式 `1/(60+rank)`

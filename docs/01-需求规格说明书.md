## 1. 引言

### 1.1 项目背景
在数字化与智能化深度融合的时代，高等教育面临标准化教学难以满足个性化学习需求的挑战。学生在知识基础、学习能力、兴趣方向上的差异，使得统一的课堂教学无法兼顾每位学生的节奏。大模型技术的突破，为构建个性化学习系统提供了全新的技术可能。

### 1.2 项目目标
构建一个基于多智能体协同的个性化学习系统，通过对话式画像构建、多智能体资源生成、学习路径规划、智能辅导与效果评估五大核心功能，实现"因材施教"的数字化落地。

### 1.3 参考项目
- [NPUYUN/LearnPath](https://github.com/NPUYUN/LearnPath) — 同赛题优秀作品，提供了 AI 课堂、实时学情、多通道 LLM 路由等创新设计参考
- [a3341777420-jpg/A3-learning-agent](https://github.com/a3341777420-jpg/A3-learning-agent) — 同赛题作品，展示了英语学习场景的多智能体应用

## 2. 功能性需求

### 2.1 对话式学习画像自主构建（必选）

#### F-1.1 对话特征抽取
- **描述**：系统通过自然语言对话自动抽取学生特征，无需传统表单填写
- **输入**：学生自然语言对话内容
- **处理**：规则引擎 + LLM 分析提取8个维度的特征信息
- **输出**：结构化的画像维度数据（数值 + 等级 + 证据）

#### F-1.2 多维画像构建（≥8维）
- 知识基础：已掌握知识点与课程基础
- 认知风格：视觉型/听觉型/动手型、抽象/具象思维
- 学习偏好：偏好的学习方式
- 薄弱环节：易错点和知识盲区
- 学习目标：考试/竞赛/科研/就业
- 时间管理：可用学习时间和节奏
- 自我效能：学习信心和自主能力
- 交互模式：主动提问型/被动接受型/合作学习型

#### F-1.3 画像动态更新（随学随新）
- **实时学情**：每次对话后分析学生的困惑度、投入度、认知负荷、情绪状态
- **长期画像**：累积多轮对话，渐进式完善画像
- **更新策略**：增量更新 + 指数衰减 + 状态平滑融合

### 2.2 多智能体协同的资源生成（必选）

#### F-2.1 多智能体架构
- ProfileAgent（画像分析师）
- CourseExpertAgent（课程文档 + 拓展阅读）
- QuizGeneratorAgent（练习题目生成）
- PathPlannerAgent（学习路径规划）
- MultimodalAgent（思维导图 + 代码案例）
- TutorAgent（智能答疑辅导）
- EvaluatorAgent（学习效果评估）
- ReviewerAgent（资源质量审查）

#### F-2.2 资源类型（≥6种）
1. 专业课程讲解文档（Markdown）
2. 知识点思维导图（Mermaid）
3. 多种类型练习题目（选择/填空/简答/编程/判断）
4. 拓展阅读材料
5. 代码实操案例
6. 教学课件提纲

#### F-2.3 协同工作机制
- 意图识别：关键词规则 + LLM 意图分类
- 任务编排：优先级 + 依赖关系的任务 DAG
- 并行执行：同优先级 Agent 并行调用
- 结果聚合：多 Agent 输出合并为完整学习方案

### 2.3 个性化学习路径规划（必选）

#### F-3.1 路径规划
- 基于画像 + 课程知识图谱生成有序学习步骤
- 每个步骤包含：学习内容、预计时长、推荐资源、前置要求、评估方式
- 支持3-6个阶段的层次化规划

#### F-3.2 路径动态调整
- 实时学情驱动：困惑度高时自动建议放慢或补充基础
- 评估驱动：测验结果不理想时触发针对性调整
- 兴趣驱动：好奇心高时引入拓展内容

### 2.4 智能辅导（加分项）

#### F-4.1 多模态答疑
- 文字解答：详细步骤拆解 + 生活化类比
- 图解说明：Mermaid 流程图/示意图
- 代码演示：完整实例 + 逐行注释

#### F-4.2 个性化辅导策略
- 实时学情驱动教学策略：困惑高 → 降压模式，挫败 → 共情模式
- 认知风格适配：视觉型 → 多用图，动手型 → 多给代码示例

### 2.5 学习效果评估（加分项）

#### F-5.1 多维度评估
- 知识掌握度（练习正确率）
- 应用能力（编程题/应用题完成度）
- 学习持续性（连续学习天数、投入时长）
- 进度完成率（路径进度、资源完成率）

#### F-5.2 评估驱动的动态调整
- 评估结果反馈到画像更新
- 触发路径重规划
- 调整资源推荐策略

## 3. 非功能性需求

### 3.1 用户体验
- 界面美观大方，符合现代 AI 产品交互规范
- 流式输出：SSE 逐字推送，提供生成进度感知
- Markdown 渲染：支持代码块、表格、公式、Mermaid 图表
- 响应时间：核心问答 < 5秒，资源生成提供进度追踪

### 3.2 安全与可靠性
- 防幻觉机制：RAG 来源引用 + 一致性检查 + Reviewer 质检
- 内容安全过滤：敏感词检测 + 学术诚信检查
- LLM 多通道降级：Kimi → 星火 → 辅助 → Mock 自动路由
- 异常恢复：LLM 调用失败时自动重试 + 降级兜底

### 3.3 合规要求
- AI 工具须选用科大讯飞相关工具（支持星火 Spark API）
- 开源项目标注名称、来源及协议
- 课程知识库自行构建

## 4. 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                      前端层 (Vue3)                        │
│  对话界面 │ 画像面板 │ 资源库 │ 学习路径 │ 评估看板       │
├─────────────────────────────────────────────────────────┤
│                     API 层 (FastAPI)                      │
│  REST + SSE流式 + JWT认证 + CORS                         │
├─────────────────────────────────────────────────────────┤
│              多智能体编排层 (Orchestrator)                 │
│  意图识别 → 任务DAG → 并行执行 → 结果聚合                 │
├──────────┬──────────┬──────────┬──────────┬────────────┤
│ Profile  │ Course   │ Quiz     │ Path     │ Tutor      │
│ Agent    │ Expert   │ Generator│ Planner  │ Agent      │
├──────────┼──────────┼──────────┼──────────┼────────────┤
│Multimodal│Evaluator │Reviewer  │                          │
│ Agent    │ Agent    │ Agent    │                          │
├─────────────────────────────────────────────────────────┤
│                    服务层 (Services)                       │
│  实时学情感知 │ LLM降级路由 │ 内容安全过滤 │ RAG检索      │
├─────────────────────────────────────────────────────────┤
│                    数据层                                  │
│  SQLite │ ChromaDB │ 课程知识库 │ 向量存储                 │
└─────────────────────────────────────────────────────────┘
```

## 5. 技术选型

| 层级 | 技术 | 选型原因 |
|------|------|---------|
| 后端框架 | FastAPI + Uvicorn | 高性能异步，原生支持 SSE |
| 前端框架 | Vue3 + TypeScript + Vite | 生态成熟，响应式数据流 |
| LLM 主通道 | 科大讯飞星火 Spark v3.5 | 赛题要求 |
| LLM 备选 | Kimi / OpenAI 兼容 | 生产可用性增强 |
| 向量数据库 | ChromaDB | 轻量，无外部依赖 |
| 关系数据库 | SQLite | 部署简单，竞赛环境友好 |
| 图表 | ECharts | 功能丰富，国内生态好 |

## 6. 验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC-1 | 画像维度 | ≥6维，含数值 + 等级 |
| AC-2 | 资源类型 | ≥5种，每种独立 Agent 生成 |
| AC-3 | 路径规划 | 含前置依赖 + 预计时长 |
| AC-4 | 流式输出 | SSE 逐字推送 |
| AC-5 | 防幻觉 | Reviewer 质检 + 来源引用 |
| AC-6 | 内容安全 | 敏感词过滤生效 |
| AC-7 | 讯飞集成 | Spark API 正常调用 |
| AC-8 | 知识库 | 自建课程知识库可检索 |

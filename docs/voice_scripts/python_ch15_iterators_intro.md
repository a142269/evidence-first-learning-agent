同学们好,这一讲我们深入 Python 迭代器与生成器。

什么是迭代器?它是实现了两个特殊方法的对象:__iter__ 返回自身,__next__ 返回下一个值或抛 StopIteration。Python 的 for 循环本质上就是反复调用 next()。当你用 for i in [1, 2, 3] 时,Python 内部会调用 iter(list) 拿到迭代器,然后不停调用 next() 直到 StopIteration。

def gen(): yield 1 yield 2,这个 gen 函数就是一个生成器,自动实现了迭代器协议。yield 是暂停,next 是恢复。每次 yield 都会保存函数的局部状态,包括所有变量。生成器用起来像函数,但行为像迭代器。

为什么需要生成器?因为它支持惰性计算——只在需要时才计算下一个值,不预先计算所有值。想象一下,如果你要处理一个 10GB 的日志文件,用 read 一次性加载到内存,程序肯定崩。但用生成器逐行处理,内存占用几乎恒定。生成器特别适合大文件处理、无限序列、数据管道。

比如斐波那契数列,可以无限生成下去,需要时取一段。Python 的 itertools 模块提供了大量迭代器工具:count 无限计数,chain 拼接迭代器,islice 切片,takewhile 满足条件则取,groupby 分组,product 笛卡尔积。掌握这些工具,你的代码会简洁很多。

还有一个高级用法叫 yield from,可以委派给子生成器,是 Python 异步编程的前身。Python 3.5 引入的 async await 语法,本质就是 yield from 的语法糖。

学完这一讲,你应该掌握:写生成器函数、用生成器表达式节省内存、组合迭代器构建数据管道。生成器是 Python 中"惰性计算"的核心,从大文件处理到数据科学,都离不开它。

还有一种特殊的迭代器叫 async generator,它在异步 I/O 场景中扮演重要角色。Python 3.6 引入了 async for 语法,可以在协程中异步迭代。理解这些概念,能帮助你过渡到 asyncio 异步编程。

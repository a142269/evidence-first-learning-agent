## 2. 完整生命周期

【重音】一个 AI 项目的完整生命周期,通常包括六个阶段。

【停顿】第一,【重音】需求分析——明确痛点。在 A3 项目里,痛点是"传统线上课程千人一面,缺乏个性化辅导"。

第二,【重音】数据与知识工程——准备训练数据、构建 RAG 知识库、设计题目 JSON。

第三,【重音】模型与架构设计——选基座模型,设计多 Agent 协作架构。

第四,【重音】系统评估——用批量测试集打分,比如 100 个学生问题测 RAG 命中率。

第五,【重音】部署——Docker 容器化,让系统能一键启动。

第六,【重音】监控——上线后看响应时延、API 成本、异常报错率。【停顿】

## 3. 可演示的最小闭环

【停顿】在准备比赛答辩时,【重音】最重要的事情是"端到端跑通一个最小闭环"。

A3 的最小闭环是这六步:

【停顿】第一步,【重音】画像——系统展示学生当前掌握度。

第二步,【重音】提问——学生输入"我不懂注意力机制"。

第三步,【重音】知识库检索——系统从课程知识库召回相关章节。

第四步,【重音】资源生成——Tutor Agent 输出讲解,带思维导图。

第五步,【重音】练习与评估——学生做题,Evaluator Agent 判错归因。

第六步,【重音】反馈更新——Profile Agent 调整学生掌握度。

【重音】这六步全部跑通,就是评委眼中"有闭环、有证据、可复现"的好项目。【停顿】

## 4. 验收指标

【停顿】光跑通还不够,【重音】必须有量化指标证明你的项目是"有效且好用"。

A3 项目的核心指标包括:知识库命中率(目标 > 90%)、生成准确率、响应时延(TTFT < 3 秒)、题目覆盖率、学习路径可解释性。

【停顿】这些指标必须用一份"前后对比"表格来呈现——优化前 vs 优化后,数字变化了多少。【重音】没有数字的"我感觉很好",在评委眼里基本不算数。【停顿】

## 5. 答辩材料

【重音】最后说说答辩材料。

【停顿】第一,【重音】核心截图——不要只截干瘪的网页,要截"知识库溯源徽章"、"Agent 思考链条暴露"等精彩瞬间。

第二,【重音】Benchmark 表格——50-100 道真实测试题,列出优化前后的指标对比。

第三,【重音】复现命令——`docker-compose up -d` 一行命令,别人就能跑起来。

第四,【重音】风险与局限性——主动说明系统在并发、幻觉等方面的局限,这反而体现你的工程深度。【停顿】

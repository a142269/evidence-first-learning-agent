同学们好,这一讲我们聊一聊 Python 函数。

函数是什么?简单说,函数就是把一段可复用的代码打包起来,给它起个名字,以后想用的时候叫一下名字就行。

在 Python 里,定义函数非常简单。def 关键字,函数名,圆括号,冒号,下面缩进的部分就是函数体。比如 def greet(name): return "Hello, " + name,这样我们就定义了一个叫 greet 的函数。以后每次调用 greet("Alice"),它就会返回 "Hello, Alice"。

Python 的函数有几个特别的地方。第一,函数是一等公民——可以赋值给变量,可以作为参数传递,可以作为返回值,可以存入容器。这给函数式编程和高阶函数打下了基础。第二,函数支持多种参数形式:位置参数、关键字参数、默认参数、可变参数 *args 和 **kwargs。第三,Python 有一个独特的概念叫闭包,函数可以"记住"它定义时的环境,实现状态保持。

我们这一讲还会学到装饰器。装饰器本质上是一个"包装函数"的可调用对象,可以在不修改原函数的情况下给它加功能。比如计时器、日志、重试、权限校验,这些都是装饰器的经典应用。Web 框架 Flask 和 Django 的中间件机制,本质上就是装饰器链。

最后,记住一句话:好的函数应该职责单一、命名清晰、有文档字符串。代码即注释,简洁胜于复杂。函数不要写得太长,超过 20 行就应该考虑拆分;参数不要太多,超过 5 个就应该考虑用 dataclass 包装。

函数式编程是 Python 的一个重要范式。map、filter、reduce、partial 这些工具,虽然不像 Haskell 那样是核心,但在数据处理时非常实用。functools.lru_cache 可以自动缓存函数结果,functools.total_ordering 可以自动补齐比较方法,这些都是 Pythonic 的函数式工具。

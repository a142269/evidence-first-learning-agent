同学们好,这一讲是 Python 面向对象编程的第一课。

什么是面向对象?简单说,就是用"类"和"对象"来组织代码。类是一个蓝图,定义了对象应该有什么数据、能做什么事。对象是类的实例,是真实存在的东西。

在 Python 里,定义一个类用 class 关键字。比如 class Dog,里面可以放属性(数据)和方法(行为)。def __init__(self, name): self.name = name,这就是构造函数,创建 Dog 对象时自动调用,设置名字。self 是约定(不是关键字),代表当前实例。

Python 的面向对象有几个独特之处。第一,Python 没有真正的"私有"——用单下划线表示内部使用,双下划线通过名称改写防止意外覆盖。第二,Python 支持多重继承,通过 MRO 算法和 C3 线性化解决菱形继承问题。第三,Python 推崇"鸭子类型"——只要对象有需要的方法,就能用,不强制继承关系,这让代码更灵活。第四,Python 的 @property 装饰器可以把方法变成属性,在保持接口简洁的同时加入校验逻辑。

这一讲我们重点掌握四个概念:self 代表当前实例;实例属性和类属性的区别;@classmethod 和 @staticmethod 的应用场景;@property 把方法变成属性。

面向对象不是为了用而用。当你的程序有"对象"的概念、且有"行为"需要封装时,OOP 就派上用场了。简单脚本不需要复杂的类层次。记住三大特性:封装把数据与行为打包,继承实现代码复用,多态让接口统一。

@property 是 Python 独有的特性,其他语言很少有。它把方法变成属性,用户可以像访问属性一样使用,但背后可以加校验、计算、通知等逻辑。@classmethod 让你写"替代构造方法",@staticmethod 让你组织与类相关的工具函数。这三个装饰器掌握好,OOP 就入门了。

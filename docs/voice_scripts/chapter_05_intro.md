## 2. 为什么需要 Transformer

【重音】在 Transformer 出现之前,自然语言处理主要依赖 RNN 和 LSTM。它们有两个致命缺陷:第一,必须逐字处理,无法并行训练;第二,当句子超过几十个字,前面的信息就会被"遗忘"。

【停顿】想象一下,【重音】你正在读一本很厚的侦探小说,读到最后一章时,前面伏笔已经忘记得差不多了,这时候你就很难把"凶手是谁"和"第三章埋的线索"关联起来。

Transformer 的出现,就像给了你一个【重音】"一眼通读全本"的能力——它能同时处理整段文字,精准捕捉任意两个词之间的关联,这在技术上叫做 Self-Attention,自注意力机制。【停顿】

---

## 3. 核心直觉

【重音】我们来打个比方。课堂上老师在讲课,有的同学在认真记笔记,有的在走神。如果老师问:"刚才我说了什么?",走神的同学通常答不上来——因为他没有"关注"。

Transformer 的自注意力机制,就是给每个词都装上了一个【重音】"关注度分配器":它会自动判断"当前这个词,应该重点关注前面哪些词",然后按这个权重重新组合信息。

这种"关注度"是用三个向量来算的——Query(查询)、Key(键)、Value(值)。【停顿】同学们不必死记硬背公式,只要记住一句话:【重音】Q 代表"我要找什么",K 代表"我是谁",V 代表"我有什么信息"。

---

## 4. Multi-Head 与大模型

【停顿】更进一步,Transformer 还设计了【重音】多头注意力(Multi-Head Attention),把"关注"这件事拆成多个角度同时进行——有的头关注语法,有的头关注语义,有的头关注上下文关联。

这种"分工协作"的设计,正是它强大的根源。

【重音】基于这套架构,OpenAI 训练出了 GPT 系列,Google 训练出了 BERT 系列,我们国产的通义千问、文心一言也都在同一条技术路线上。当你看到一篇 1000 字的文章,大模型可以"读一遍"就抓住所有要点,这就是 Transformer 给我们的礼物。【停顿】

---

## 5. A3 项目中的应用

【停顿】那这套技术,和我们的 A3 个性化学习系统有什么关系呢?【重音】关系非常大。

在 A3 系统里,【重音】大模型是真正的"中央大脑"——它驱动 Planner Agent 帮你规划学习路径,驱动 Tutor Agent 给你讲知识点,驱动 Quiz Agent 给你出题,驱动 Evaluator Agent 帮你批改与归因。

但请记住一点:【重音】大模型的输出不等于事实。它有时会一本正经地"胡说八道",这叫"幻觉"。所以 A3 系统会先用 RAG 技术,从课程知识库中检索真实内容,再让大模型"开卷答题"——这正是我们后面 RAG 章节要展开的内容。【停顿】

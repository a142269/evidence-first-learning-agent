## 1. 开场

【停顿】同学们好,这一章我们来聊一个让 AI 从"被动回答"走向"主动做事"的概念——【重音】AI Agent,智能体。

如果说大模型是一个"超级大脑",那 Agent 就是【停顿】一个会使用工具、有长期记忆、能自我反思的"完整个体"。【停顿】

---

## 2. Agent 的核心要素

【重音】一个完整的 AI Agent,通常包含六大要素:

【停顿】第一,【重音】目标——它知道自己要完成什么任务。

第二,【重音】状态——它能感知当前环境处于什么情况。

第三,【重音】规划——它能把大目标拆成一步步小目标。

第四,【重音】工具——它会调用 API、查数据库、执行代码。

第五,【重音】记忆——它能记住过去几轮的对话,甚至跨会话的长期信息。

第六,【重音】反馈——它能根据结果自我评估、调整策略。【停顿】

---

## 3. 核心范式

【停顿】目前主流的 Agent 范式有四种:

【重音】ReAct——边想边做,Reason + Act,每一步都先思考再行动,适合探索性任务。

Plan-and-Execute——先想完整计划,再一步步执行,适合目标明确的任务。

【重音】Reflection——做完之后回头审视,主动发现错误并改正,适合高精度任务。

Tool Calling——把工具调用作为"特殊动作",让模型能精确控制外部 API。【停顿】

## 4. A3 中的 Agent

【停顿】A3 系统里的 Agent 不是孤立的,而是组合起来的多智能体团队。

Planner Agent 是"调度中心",【停顿】接收学生请求,决定调用谁。Course Expert Agent 是"知识库专家",【停顿】负责 RAG 检索。Tutor Agent 是"主讲老师",【停顿】负责把知识讲清楚。Quiz Agent 是"出题官",【停顿】根据 Bloom 层级动态出题。Evaluator Agent 是"评估官",【停顿】判分并归因。Profile Agent 是"档案员",【停顿】更新学生掌握度。【停顿】

---

## 5. 失败模式

【停顿】Agent 也有它的"坑"。

【重音】目标漂移——聊着聊着忘了最初要干什么。

工具误用——调错 API,把不相关的工具当主菜。

死循环——反复调用同一个工具,拿不到结果。

事实幻觉——基于错误的"内部知识"做出推断。

A3 的对策:【停顿】每一步都加超时、加最大重试次数、加人工审核入口;所有"内部知识"必须可追溯到外部知识库。【停顿】

## 三、多智能体协同流程

```mermaid
sequenceDiagram
    participant U as 学生用户
    participant FE as Vue3前端
    participant API as FastAPI Gateway
    participant ORC as Orchestrator
    participant PA as ProfileAgent
    participant CE as CourseExpert
    participant QG as QuizGenerator
    participant RV as ReviewerAgent

    U->>FE: "帮我讲解CNN的原理，再出几道题"
    FE->>API: POST /api/v1/chat/stream (SSE)
    API->>ORC: process_turn(message, profile, context)
    
    Note over ORC: Step1: 意图识别
    ORC->>ORC: 规则: "讲解"→generate_doc<br/>"出题"→generate_exercise
    
    Note over ORC: Step2: 任务DAG
    ORC->>PA: task_0: profile_update (priority=1)
    PA-->>ORC: profile_updates
    
    par 并行执行 (priority=2)
        ORC->>CE: task_1: generate_doc
        ORC->>QG: task_2: generate_exercise
    end
    
    CE-->>ORC: CNN讲解文档
    QG-->>ORC: CNN练习题
    
    Note over ORC: Step3: Reviewer质检
    ORC->>RV: review(doc)
    RV-->>ORC: pass=true, score=88
    ORC->>RV: review(quiz)
    RV-->>ORC: pass=true, score=92
    
    Note over ORC: Step4: 聚合+流式输出
    ORC-->>API: SSE chunks + resources
    API-->>FE: event: chunk, event: resources, event: done
    FE->>U: 流式渲染讲解文档
    FE->>U: 展示练习题卡片
```

## 四、防幻觉四级防线

```mermaid
graph TB
    Input["LLM生成内容"] --> L1
    L1["L1: RAG引用验证<br/>事实性陈述→知识库chunk追溯"]
    L1 -->|通过| L2
    L1 -->|可疑| Flag["标记'待核实'"]
    L2["L2: 内容安全过滤<br/>敏感词匹配+正则模式，lt5ms"]
    L2 -->|通过| L3
    L2 -->|命中| Block["拦截，返回安全提示"]
    L3["L3: 一致性检查<br/>生成内容 vs RAG context相似度对比，lt50ms"]
    L3 -->|一致| L4
    L3 -->|不一致| Flag
    L4["L4: Reviewer质检<br/>快速规则检查lt5ms + LLM深度审查lt3s"]
    L4 -->|pass| Output["安全输出"]
    L4 -->|fail| Regenerate["触发重生成"]
```

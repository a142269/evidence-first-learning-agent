## 4. 性能测试

| 指标 | 目标 | 实测方法 |
|------|------|---------|
| API 响应时间（简单问答） | < 3秒 | Postman / curl 计时 |

| 画像分析（实时学情） | < 100ms | 后端日志分析耗时 |

## 6. 常见问题排查

| 问题 | 检查项 |
|------|--------|
| 前端无法连接后端 | 后端是否启动，CORS 是否配置，端口是否冲突 |
| API 返回空内容 | .env 是否配置了 API Key，LLM 通道是否可用 |
| 流式输出中断 | SSE 连接是否超时，查看后端日志 |
| 知识库检索无结果 | 是否执行了知识库索引，knowledge_base 目录是否有文件 |
| 画像不更新 | 是否至少完成了一轮对话，检查 profile_updates 提取逻辑 |

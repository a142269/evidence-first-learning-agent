## 一句话定位

**智学领航** 是基于 DINA 认知诊断 + Multi-Agent Debate + GraphRAG 的精准教育多智能体系统，**12 个 Agent + 1 个 Orchestrator** 协同为大学生提供个性化、多模态的学习体验。


## 与我们竞争作品的根本差异

| 维度 | 多数作品 | **智学领航（我们）** |
|------|---------|-------------------|
| 画像 | 填表单 → 静态标签 | **对话式 8 维动态画像** + 实时学情 6 维感知 |
| 资源生成 | LLM 单次生成 | **Multi-Agent Debate**：Expert 生成 → Critic 质疑 → 辩论重写 |
| 防幻觉 | RAG 检索 + 提示词约束 | **4 级防线**: RAG + Reviewer + 一致性检查 + **CoV 声称级验证** |
| 算法深度 | 无算法 | **DINA 认知诊断** (EM) + **BKT 知识追踪** + **SM-2 间隔重复** |
| 创新原创 | 工程堆砌 | **3 个可发表原创**: Bloom-Aware Reflection / DINA-CoV / 学习时光机 |
| 多模态 | 文本 | **真 6 种产物**: PPTX / MP3 / Mermaid PNG / Manim 动画 / 代码 / SVG |

## 5 大核心功能速览

| # | 功能 | 体验方式 | 关键文件 |
|---|------|---------|---------|
| 1 | **对话式画像构建** | ChatView → 开始对话 → 系统自动更新画像 → ProfileView 看 8 维雷达 | `agents/profile_agent.py` |

## 四、知识库文档质量规范

### 每份知识文档应包含：

1. **标题结构**：使用 `# ## ###` 三级标题
2. **知识点元数据**（YAML frontmatter）：
   ```yaml
   ---
   id: AI_006_01
   name: 卷积神经网络CNN
   difficulty: 5
   tags: [CNN, 深度学习, 计算机视觉]
   prerequisites: [AI_006]
   ---
   ```
3. **正文内容**：概念定义 → 核心原理 → 数学公式 → 图示（Mermaid）→ 代码示例 → 应用场景
4. **练习思考**：每章至少3个复习问题
5. **参考文献**：标注信息来源

## 六、快速填充脚本

如果需要快速生成知识库框架，可使用以下Python脚本：

```python
# scripts/bootstrap_knowledge_base.py
"""快速生成知识库文件骨架"""
import os

KB_PATH = "knowledge_base/artificial_intelligence"

chapters = {
    "01-人工智能概述.md": "# 人工智能概述\n\n## 1.1 什么是人工智能\n\n...\n\n## 1.2 AI的发展历史\n\n...",
    "04-机器学习基础.md": "# 机器学习基础\n\n## 4.1 什么是机器学习\n\n...\n\n## 4.2 监督学习与无监督学习\n\n...",
    "06-神经网络与深度学习.md": "# 神经网络与深度学习\n\n## 6.1 从感知机到深度学习\n\n...",
    # ... 更多章节
}

for filename, content in chapters.items():
    filepath = os.path.join(KB_PATH, filename)
    os.makedirs(os.path.dirname(filepath), exist_ok=True)
    with open(filepath, 'w', encoding='utf-8') as f:
        f.write(content)
    print(f"Created: {filepath}")
```
